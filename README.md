# Radio Musicólogos - Pioneer DEH-4250BT (Edición Local)

Este proyecto es una aplicación web interactiva que simula un autorradio Pioneer real con ecualizador de 7 bandas por Web Audio API, efectos visuales reactivos a los graves y personalización de luces (Illumi).

## Instrucciones para ejecutar en local

1. Descomprime este archivo.
2. Abre una terminal dentro de la carpeta descomprimida.
3. Instala las dependencias ejecutando:
   ```bash
   npm install
   ```
4. Inicia el servidor de desarrollo:
   ```bash
   npm run dev
   ```
5. Abre en tu navegador el enlace local mostrado en pantalla (usualmente `http://localhost:5173`).

## Despliegue en Vercel

1. Sube este proyecto a un repositorio de GitHub / GitLab.
2. Conecta tu cuenta de Vercel a GitHub e importa este repositorio.
3. Vercel detectará Vite automáticamente y desplegará tu aplicación sin configuraciones adicionales.
